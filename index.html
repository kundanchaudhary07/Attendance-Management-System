The DSA Underneath C++ ⇄ JS, SAME LOGIC

Linked List

Every student is a node with a next pointer. Enrolling inserts at the head in O(1); deleting relinks neighbours.

Hash Map

Roll number → node reference. Search and delete-by-roll run in O(1) instead of scanning the whole list.

Merge Sort

Rankings are produced by a hand-written merge sort over attendance percentage, O(n log n), not a built-in sort.

This is the actual C++ this register is based on (download it from the chat as StudentAttendanceSystem.cpp). Below is the merge sort, the core sorting logic, shown here for reference:

void mergeSort(vector<Student*>& arr, int l, int r, bool descending) {
    if (l >= r) return;
    int m = l + (r - l) / 2;
    mergeSort(arr, l, m, descending);
    mergeSort(arr, m + 1, r, descending);
    merge(arr, l, m, r, descending);
}

void merge(vector<Student*>& arr, int l, int m, int r, bool descending) {
    vector<Student*> left(arr.begin() + l, arr.begin() + m + 1);
    vector<Student*> right(arr.begin() + m + 1, arr.begin() + r + 1);
    size_t i = 0, j = 0; int k = l;
    while (i < left.size() && j < right.size()) {
        bool cond = descending
            ? (left[i]->percentage() >= right[j]->percentage())
            : (left[i]->percentage() <= right[j]->percentage());
        if (cond) arr[k++] = left[i++]; else arr[k++] = right[j++];
    }
    while (i < left.size()) arr[k++] = left[i++];
    while (j < right.size()) arr[k++] = right[j++];
}
